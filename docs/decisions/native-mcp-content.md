# D-043 — Contenido MCP nativo del proxy de Plugins

29 de octubre de 2026. Continúa Plugins independiente de Encargos. Cambio local del formato de salida conversacional y transporte, sin UI, preferencias, migración o dependencia nueva.

## Problema y diseño

plugin_mcp_run entregaba el resultado externo entero dentro de un JSON de texto y structuredContent. Una imagen, audio o recurso llegaba como datos serializados, y el isError exterior permanecía falso incluso cuando la herramienta externa notificaba error. La interfaz humana plugin_request ya recibía el resultado original y conserva ese comportamiento.

Kernel/mcp añade with_content para separar bloques nativos de los datos locales, junto a with_image existente. No conoce fuentes de Plugins, no resuelve URI ni descarga archivos. Registry conserva orden, contenido y error del adaptador, anteponiendo la descripción JSON local. El formato de las capturas propias y su consumidor del constructor permanecen intactos.

El adaptador de Plugins sigue retirando _meta del protocolo exterior, bloques y recursos embebidos; no recorre structuredContent, donde esa clave puede ser dato del servicio. Mueve content a los bloques MCP exteriores, conserva source, estado, intento/diario, revisión y result con sus datos estructurados/isError, e indica content_delivery=native. No duplica el binario dentro del JSON textual o estructurado local. Las anotaciones y los tipos texto/imagen/audio/resource_link/resource se conservan. Un enlace sigue siendo una referencia, sin nuevo permiso o transporte automático de recursos. Los consumidores reciben datos no confiables, nunca instrucciones del sistema.

La reducción de respuestas grandes elimina exclusivamente el primer texto si es copia exacta del JSON estructurado local. Antes retiraba también textos del servidor que podían ser información única. Si aun así no cabe dentro del límite existente de cuatro MiB, conserva el error explícito response_too_large/outcome=unknown, sin cortar el canal, afirmar éxito o autorizar reenvío. No modifica el diario ni sus bloqueos por resultados inciertos.

Referencia técnica: [MCP 2025-06-18, resultados y errores de herramientas](https://modelcontextprotocol.io/specification/2025-06-18/server/tools), consultada el 29 de octubre. La implementación usa los tipos de contenido de esa versión; no implica compatibilidad completa con todos los recursos/extensiones MCP o percepción multimodal de un modelo.
